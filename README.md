# C# Refactoring and Design Patterns

[![check](https://github.com/I-ll-Be-Backend/csharp-refactoring-and-design-patterns/actions/workflows/check.yml/badge.svg)](https://github.com/I-ll-Be-Backend/csharp-refactoring-and-design-patterns/actions/workflows/check.yml)

Code from the [I'll Be Backend](https://www.youtube.com/@illbebackend) videos: messy C# code gets better, one small, safe refactoring at a time. Every lesson has a video, an [interactive version](https://illbebackend.dev) you can step through, and a folder here with the code after every step.

## Principles

| Lesson | Steps | Video | Interactive |
|---|---|---|---|
| [DRY: one rule, one place](dry/) | 11 | [Watch](https://www.youtube.com/watch?v=J156aSo8YNw) | [Open](https://illbebackend.dev/lessons/dry/csharp/) |

## How to use it

- Open a lesson folder and read its README, then the step folders in order.
- `sh check.sh` compiles every step in Docker with `mcr.microsoft.com/dotnet/sdk:8.0`, the same check that runs on every push.
- Found a bug in a lesson? Open an issue.
